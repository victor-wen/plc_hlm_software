# RTU 模拟器验收程序（spec §15.5）

本文档定义阶段 4「模拟 PLC RTU 验收」的执行程序、场景表和报告模板。
验收对象是独立 `plc_simulator.exe` + 虚拟 COM 对 + 生产 `QtModbusPlcGateway`
（`hlm_app.exe --real`）构成的完整链路。

> **重要声明：** 真实 H3U 现场 SAT（spec §15.6）**未完成**。模拟 PLC 验收通过
> **不能替代**真实 H3U 现场 SAT；投产前必须按 spec §15.6 追加现场验收。

## 1. 前置条件

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x64 |
| 虚拟 COM 驱动 | com0com（https://com0com.sourceforge.net/）或等价驱动，已安装并创建 COM 对 |
| 软件包 | Task 21 打包产物 `plc-hmi-<version>-win64.zip`（含 `hlm_app.exe`、`plc_simulator.exe`、全部运行依赖） |
| 部署检查 | 已通过 `scripts/check_deploy_deps.ps1`（qwindows.dll、qsqlite.dll、Qt6SerialBus/SerialPort、libcrypto、opencv_core、MSVC 运行库、LICENSES/） |
| 数据库 | 首次启动自动建库（spec §12）；验收前可删除 `%ProgramData%\PLC-HLM\app.db` 以重置 |

## 2. 环境准备

1. 解压发行包到干净目录，例如 `C:\plc-hmi\`。
2. 用 com0com 创建虚拟 COM 对，例如 **COM3 ↔ COM4**（记录实际端口号）。
3. 启动模拟器：运行 `plc_simulator.exe`，在控制面板中设置：
   - 端口：`COM4`（对的一端）
   - 波特率：`9600`（或 19200，按场景）
   - 站号：`1`
   - 点击「启动」；状态栏显示启动成功。
4. 启动上位机：运行 `hlm_app.exe`（真实 Modbus RTU 网关为默认模式；
   `hlm_app.exe --real` 也可显式指定）。
   - 首次启动进入设置页，配置 COM 口 = `COM3`（对的另一端）、站号 = `1`、
     波特率 = 与模拟器一致，保存。
   - 回到主界面，确认通讯状态为「在线」、快照数据开始刷新。

> 说明：串口参数（COM/波特率/站号）在设置页配置并持久化（spec §8.1），
> 命令行提供 `--real`（生产网关，默认）与 `--sim`（进程内模拟）选择。

## 3. 场景表

每个场景记录：**结果**（通过/失败）与**证据**（截图/日志文件/时间戳）。
日志：调试包可用 `QT_LOGGING_RULES="qt.modbus.debug=true;qt.modbus.lowlevel.debug=true"`
启用逐帧日志；生产默认关闭逐帧日志（spec §17）。

| # | 场景 | 操作步骤 | 期望结果 | 结果 | 证据 |
|---|---|---|---|---|---|
| S1 | 功能码 01（读线圈） | 主界面观察 M 区状态（如 M100/M42/M106-M111） | 状态随模拟器线圈变化刷新，通讯日志出现功能码 01 请求 | | |
| S2 | 功能码 03（读保持寄存器） | 观察 D 区数据（D126/D127、D136/D137、D138/D139、D210） | 数值与模拟器一致，通讯日志出现功能码 03 请求 | | |
| S3 | 功能码 05（写单线圈） | 执行一次启动/停止操作（写 M42/M106-M111） | 模拟器对应线圈翻转，通讯日志出现功能码 05 请求 | | |
| S4 | 功能码 06（写单寄存器） | 执行一次调宽写入（写 D136/D137 或 D138/D139） | 模拟器寄存器更新，通讯日志出现功能码 06 请求 | | |
| S5 | 9600 波特率核心流程 | 9600 下完成：复位→配方→调宽→自动→启动→停止 | 全流程成功，无超时/重试风暴 | | |
| S6 | 19200 波特率核心流程 | 19200 下重复 S5 | 全流程成功 | | |
| S7 | 单请求约束 | 观察通讯日志 30 秒 | 任意时刻在途请求不超过 1 个（无并发帧） | | |
| S8 | 写优先 | 持续轮询时发起写操作 | 写请求优先于轮询快照被发送 | | |
| S9 | 轮询防饥饿 | 持续写压力下观察轮询 | 轮询请求仍周期性发出，不被写请求饿死 | | |
| S10 | 脉冲 ≥100 ms | 触发一次脉冲输出（如点动），用示波器/逻辑分析仪或模拟器记录 | 高电平持续时间 ≥100 ms | | |
| S11 | 快照 250 ms 名义调度 | 无写压力，记录快照时间戳 10 秒 | 快照间隔约 250 ms（名义调度） | | |
| S12 | 写压力下快照 ≤1 s | 持续写压力下记录快照时间戳 | 正常通讯下 1 秒内至少 1 份快照 | | |
| S13 | 三次失败离线 | 模拟器停止响应（断开 COM 或停止服务） | 连续 3 次失败后状态置为「离线」 | | |
| S14 | D140 三秒冻结 | 通讯中断后观察 D140 | D140 保持最后值 3 秒后冻结/回绕（按 spec §15.2 语义） | | |
| S15 | 退避重连 | 恢复模拟器服务 | 按退避策略自动重连，恢复在线 | | |
| S16 | 无命令重放 | 重连后观察 | 离线期间积压的命令不被重放执行 | | |
| S17 | M112 停止清位 | 触发 M112 停止翻转 | 2 秒内 M42/M106-M111 被清除，M100 保持 | | |
| S18 | M112 翻转应答 ≤1 s | 正常写压力下连续翻转 M112 | 相邻两次翻转的成功应答间隔 ≤1 秒 | | |
| S19 | 脉冲清零最高优先级 | 脉冲输出期间发起清零 | 清零请求优先于脉冲/其他写请求 | | |
| S20 | 注入调宽失败 | 模拟器注入调宽失败（如 D110=10 或条件不满足） | HMI 显示调宽失败，不产生错误写入 | | |
| S21 | 动态超时 | 注入慢响应/超时 | 按动态超时策略重试或报错，不卡死 | | |
| S22 | 故障 1-10 | 依次注入故障代码 1-10 | 故障正确显示与锁存 | | |
| S23 | 未知代码 | 注入未知故障代码 | 按未知代码策略处理（不崩溃、有记录） | | |
| S24 | 异常响应 | 注入 Modbus 异常响应（非法功能/非法数据） | 请求被标记失败，按重试/离线策略处理 | | |
| S25 | 非法值 | 注入非法值（越界寄存器/非法数据） | 被拒绝或安全处理，不产生危险输出 | | |
