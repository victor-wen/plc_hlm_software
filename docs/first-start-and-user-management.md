# 首次启动与用户管理

## 首次启动

首次启动时，程序会创建数据库目录和 `app.db`，随后检查 `users` 表。若没有任何用户，界面会自动切换到“用户与设置”，显示“创建首位管理员”卡片。

1. 输入管理员用户名。
2. 输入并确认密码。系统没有默认用户名或默认密码。
3. 点击“创建管理员”，等待界面明确显示成功或失败。
4. 创建成功后点击“登录管理员账号”，使用刚才设置的凭据登录。

密码不会以明文保存。当前实现使用带独立随机盐的 PBKDF2-HMAC-SHA256 派生密码摘要。

## 添加后续用户

登录管理员账号后，进入“用户与设置”页面的“用户管理”区域：

1. 填写新用户名。
2. 选择“操作员”或“管理员”。
3. 填写新用户密码。
4. 点击“新增用户”。

只有收到数据库成功结果后，界面才会清空输入并刷新用户列表。用户名重复、数据库不可用等错误会直接显示在用户管理区域。

## 账户安全约束

- 连续三次登录失败后，该账号锁定 30 秒；界面对未知、密码错误、锁定和停用账号使用相同提示，避免泄露用户名是否存在。
- 不能删除当前正在登录的账号。
- 不能删除系统中最后一个可用管理员。
- 修改 D204 脉冲当量时，需要再次验证当前管理员密码。

## 数据库位置

默认路径由 Qt 的 `QStandardPaths::GenericDataLocation` 决定；在 Windows 上是 `%ProgramData%\PLC-HLM\app.db`。也可以在启动时用 `--db <path>` 指定数据库路径；指定路径的父目录不存在时，程序会自动创建。
